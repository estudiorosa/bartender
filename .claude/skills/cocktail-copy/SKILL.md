# Cocktail / menu copy

Proceso para describir un producto de forma que dé ganas de pedirlo, sin caer
en listas de ingredientes aburridas ni en adjetivos vacíos.

## Pasos

1. **Reúne los datos reales del producto** antes de escribir: ingredientes
   principales, qué lo hace distinto, sabor predominante (dulce, ácido,
   amargo, ahumado...), y cómo se sirve. Si faltan, pregúntalos — no
   inventes ingredientes ni técnicas de elaboración.
2. **Elige un ángulo**, no listes todo:
   - Sensorial (cómo sabe/huele/se ve)
   - Historia/origen (de dónde viene la receta o el nombre)
   - Ocasión (para qué momento es perfecto)
   Un buen texto de carta normalmente usa uno o dos ángulos, no los tres.
3. **Ajusta el formato al canal:**
   - Carta física: corto, entre 8-20 palabras, prioriza ingredientes clave.
   - Redes sociales: puede ser más narrativo, con gancho inicial.
   - Web: puede llevar más contexto (historia, maridaje sugerido).
4. **Evita clichés** ("explosión de sabor", "una experiencia única para tus
   sentidos"): busca una palabra o detalle concreto del producto en vez de
   una frase que serviría para cualquier cóctel.
5. **Revisa alérgenos/avisos** si el negocio los exige por normativa — si no
   sabes si aplica, pregúntalo en vez de omitirlo silenciosamente.

## Salida

Para carta: el texto final listo para maquetar, en el idioma solicitado.
Para redes: además del texto, indica si conviene acompañarlo de una llamada
a la acción (pedir, reservar, preguntar por él).
