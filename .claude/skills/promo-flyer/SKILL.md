# Promo flyer

Proceso para producir una pieza visual de promoción como Artifact, partiendo
de un concepto ya definido (idealmente con `campaign-brief` ya hecho).

## Pasos

1. **Confirma que hay un concepto claro**: nombre de la promoción, mecánica
   en una frase, fecha(s), y cualquier dato que deba aparecer (precio,
   condiciones). Si falta alguno, pídelo — un flyer con datos inventados es
   peor que no tener flyer.
2. **Antes de escribir el artifact**, carga la skill `artifact-design` para
   calibrar el nivel de diseño adecuado a una pieza promocional de una sola
   pantalla, y `artifact-diagramming` solo si la pieza necesita un elemento
   gráfico tipo diagrama (normalmente no aplica a un flyer).
3. **Contenido mínimo del flyer:** nombre de la promoción, la mecánica en una
   frase, fecha/horario, y una llamada a la acción clara (reservar, venir,
   preguntar en barra). Evita saturar de texto — un flyer se lee en segundos.
4. **Coherencia de marca:** usa el tono de `marketing/brand-voice.md`; si el
   negocio tiene colores/logo definidos, pregunta por ellos antes de elegir
   una paleta genérica.
5. Publica el resultado como Artifact HTML (una sola pantalla, diseño para
   pantalla y para imprimir si se pide explícitamente formato imprimible).

## Salida

Un Artifact con el flyer terminado. Si el flyer es para imprimir, avisa que
el formato pantalla no garantiza proporciones de impresión exactas y ofrece
ajustar tamaño/orientación si se necesita.
